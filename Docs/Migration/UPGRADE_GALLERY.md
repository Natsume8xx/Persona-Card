# 升级页与图鉴返回优化

日期：2026-09-09。以当前网页为准，不修改规则、数值或存档格式。

## 本轮实现

- 单独生成 Upgrade.prefab，在 PersonaWebAligned 场景 Editable UI 下添加实例和模板引用；其他页面没有重新烘焙。
- 升级页显示网页强化说明、目标等级、当前数值、价格及确认按钮状态，支持滚动目标列表。选择仅预览，取消不扣费。
- 图鉴从详情返回保留滚动位置；关闭后新开图鉴回到顶部。缓存仅存在当前界面会话。
- 升级渲染移入 NativeGameView.Upgrade.cs，便于后续逐页重构；这仍是同一 partial 类，不代表已经完成解耦或页面复用。
