# Unity 累计已实现功能

更新：2026-09-09。范围为 Persona-Card-main 的原生网页对齐版本，以当前网页代码为基线。以下表示已有实现，不表示已经完成全部人工验收或达到某个视觉相似度百分比。

| 模块 | 累计已实现 |
| --- | --- |
| 正式流程 | 17 核心节点：13 场战斗、N04/N08/N12 人格成长、N16 商店；成长后进入商店，合计四次商店；报告与人格带出流程 |
| 规则执行 | Unity 内执行原网页本地规则；牌型、计分、人格、Boss、商店及随机结果沿用网页模块；57 个源模块校验，非独立重写一份数值 |
| 原生界面与运行 | 原生 UGUI 页面与可编辑模板，PersonaWebAligned 场景，Windows x64 可运行构建；保留旧场景和资源 |
| 菜单与设置 | 主菜单、继续游戏、新局覆盖保护；音量、音乐、音效、亮度、动效、震动和播放速度设置；应用/取消事务；重播教学入口 |
| 阵容 | 点击与拖拽装备、交换槽位、移除、拖拽预览、取消拖拽、空槽提示、阵容不满禁止开始；调整时保留滚动位置 |
| 人格查看 | 四列原画人格图鉴（Gallery可编辑模板已更新）、已装备及待选人格详情，展示触发条件、效果与成长信息；使用已有画像资源；详情返回保留图鉴滚动位置，新开图鉴回到顶部 |
| 战斗操作 | 选牌、出牌、弃牌、手牌排序；筹码/倍率/分数预览、行动次数与目标分 HUD；牌型规则查看 |
| 战斗表现 | 发牌与出牌运动、计分数字和浮字、人格触发高亮与能量表现、加速播放；是否开启动效和震动可设置 |
| 牌库 | 当前牌库、已用、已弃三种牌堆，大小/花色排序，空牌堆状态；商店选择牌目标时保留所选目标 |
| 商店与铸造 | 商品浏览、详情、购买、刷新、目标选择、升级（已补可编辑Upgrade模板、强化说明、等级和源确认状态）、人格选择及副属性解锁、无副属性空状态及前置/阶段限制原因；列表滚动、分标签和分人格记忆位置；详情过渡及成功提示，不拦截点击 |
| 人格成长 | 新人格与槽位对照、拥有/装备数量、未装备人格摘要、替换去向与旧牌保留说明；选槽局部更新保留阅读位置，空槽文案、长确认文案适配、可关闭淡入反馈 |
| 结算与局末 | 胜负结果、基础奖励、剩余行动奖励、卡牌/人格额外金币、合计与失败差额；零奖励隐藏、奖励行和大数值适配；报告及带出入口 |
| 声音 | 人格蓄力/传递/命中三段原录音已按共用播放进度接入；原录音操作音效转发，选牌/发牌、出牌、计分录音轮播，基础战斗提示音；音乐交叉渐变、提示时压低音乐、胜负提示去重及通道回退；本轮增加共享播放池的总 10 路/同录音 3 路限制与禁用停止、空闲复用 |
| 存档与保护 | 沿用网页存档状态并保存在原生本地存储；设置单独保存；测试捕获模式不使用正式存档；生成结果恢复相关自动回归已有覆盖 |
| 验证与交付 | 保留旧回归并持续增加迁移测试；运行截图与真实 UGUI 射线/点击、拖拽检查；交付前备份、源模块和构建文件校验 |

未完成：Boss 完整音效时序、人格能量多目标路径及命中视觉的全面对齐、成长确认演出、其他页面局部更新与整体性能、逐页视觉差异穷尽审计、远程 AI 服务正式接入。当前 AI 使用本地规则校验的离线回退。
