# 人格牌：界面编辑

打开 `Assets/Scenes/PersonaWebAligned.unity`，停止 Play 后展开：

`人格牌 · 可编辑界面 > Editable UI > Battle > Content`

这里是实际 UGUI 对象。选择文字可修改 Text 的字号、颜色、对齐和字体；选择面板、图片或按钮可修改 RectTransform 和 Image/RawImage。保存场景后，运行时保留这些表现修改，分数、牌面和规则文本仍随真实游戏状态更新。

选择场景根对象，Inspector 下方有各页面的“预览 / 编辑”按钮。页面预制体保存在 `Assets/WebAligned/UI`，也可以双击进入 Prefab Mode 编辑。静态标题可以改字，动态游戏数值不应手填。编辑页面的启用状态只用于预览，Play 正常从主菜单开始。

页面模板包括主菜单、牌桌、阵容、图鉴、设置、开战、结算、牌库、牌型规则、商店、铸造、成长、报告、带出和四步教程。动态列表按实际游戏状态创建或隐藏条目。

自定义图形组件已拆成与类名一致的脚本文件，保证 Unity 可以保存预制体引用。字体采用与网页 CSS 一致的 Noto Serif SC，字体文件和 OFL 授权位于 `Assets/WebAligned/Fonts`。来源：https://github.com/google/fonts/tree/main/ofl/notoserifsc

构建读取已保存场景，不再重建空场景，也不会主动关闭交互式编辑器。`EditableUICommands.BakeAll` 仅为开发者显式生成初始模板的入口，会重建模板，不要用它保存日常界面调整。
