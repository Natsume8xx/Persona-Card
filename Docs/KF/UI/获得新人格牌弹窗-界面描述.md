# 获得新人格牌弹窗 · 界面描述

> 参考图：同目录「获得新的人格牌 的界面.png」（网页版截图，排版的首要参考）。本界面为 UI 界面重排的第一个试做界面，已实现并接入铸造流程。

## 状态与触发

- **状态**：已实现（新建 Prefab + 运行时注入，零场景改动）。
- **触发路径**（项目获得人格牌的唯一入口 = 铸造三选一）：
  - 中局铸牌（PersonaGen 生成节点）确认候选后弹窗；
  - 局终铸牌（PersonaForge）确认候选后弹窗。
- **商店不触发**：商店「增加人格牌」商品当前恒为无货（B7 模板转换后恢复上架），届时是否也走此弹窗见 Docs/代策划确认.md。

2:1 横向弹窗，居中 1280×640（1920×1080 画布，占 66.7%×59.3%，满足弹窗规范 ≤72%×84%）。层级自下而上：

| 区块 | 说明 |
|---|---|
| 根遮罩（Dim Layer） | 全屏黑 78%，raycast 拦截穿透点击，独占输入 |
| Gold Frame Outer | 外层细金描边直角边框 1290×650 |
| Panel | 深黑偏蓝渐变底 (12,16,24,250)，内层金描边 + 阴影 |
| Title Bar | 左「获得新的人格牌」；右三列统计 |
| Left Panel | 「本次获得」卡牌展示区 |
| Right Panel | 「当前装备」2×2 槽位网格 |
| Bottom Bar | 底部通栏提示条 + 左侧粗金竖线 |
| 右下角双按钮 | 「暂不替换，保留当前装备」/「替换 X 并继续」 |

## 各区块规格

### Title Bar

- 标题「获得新的人格牌」：44 号 Bold 浅米金 (232,214,173)，衬线字体（当前为系统字体近似，★预留衬线标题字体替换位）。
- 右侧三列统计（22 号）：「本次获得 1张 / 当前持有 N张 / 当前装备 n/4」。

### Left Panel（本次获得）

- 正方形金框卡牌位（★预留金色菱形发光占位图替换位）：有立绘显示立绘（PersonaArtCatalog 映射），无立绘显示金色「◇」字符（96 号）占位。
- 卡牌名：40 号 Gold Bold (178,139,73)。
- 标签「类型·映照」：20 号（按铸造候选名「mode·name」取 mode：映照/偏转/裂变）。
- 触发条件块 + 生效效果块：两块均为深色填充 + 左侧金竖线（19 号），内容由铸造候选生成（如「对子或更高」「+10 筹码」）。

### Right Panel（当前装备）

- 2×2 四槽位 Grid Layout Group（cell 286×186，间距 16/12），槽号 01~04。
- 每槽显示：槽号 + 槽内卡名（空槽显示「空槽」）；下方状态文本：选中空槽「装备至此」、选中非空「将替换」、其余「选择」。
- 普通槽深色底 (26,28,26,245) 细金框；选中槽高亮金棕 (91,70,34,255)。

### Bottom Bar

- 通栏提示条（20 号金色文字）+ 左侧粗金竖线：
  - 选中空槽：「{新卡名} → 槽位04，装备至空槽」；
  - 选中非空：「{新卡名} → 槽位02，替换 {旧卡名}（旧牌保留）」。

### 右下角双按钮

- 「暂不替换，保留当前装备」：深灰黑 (31,32,31,248) + 金描边。
- 「替换 X 并继续」：暗金填充 (46,36,18,250) Bold 浅米金；选中空槽时变体「装备至 槽位N 并继续」。

## 数据映射（网页版示例值 → 项目真实值）

| 网页版示例 | 项目真实值 |
|---|---|
| 卡牌名（如「筹码锚定者」） | 铸造候选真实 DisplayName（如「映照·洞察者」） |
| 类型·映照 | 候选名 mode 段（映照=AddChips / 偏转=AddMultiplier / 裂变=MultiplyFinal） |
| 触发条件 / 生效效果 | 现有文案生成（「{牌型}或更高：+N 筹码」拆两段） |
| 当前持有 N张 | 收藏总数（新卡入收藏之后） |
| 当前装备 n/4 | 装备槽非空计数 |
| 本次获得 1张 | 恒 1 |
| 旧牌保留 | 天然成立：收藏无上限，槽位移除旧牌仍在收藏 |

## 交互

- 默认选中第一个空槽；满槽时默认选中槽位 01；点任一槽切换目标（含音效）。
- 「暂不替换」= 新牌只入收藏不装备，关闭弹窗继续流程。
- 「替换并继续」= 替换执行（PersonaLoadoutState.EquipAt，同模板卡已在其他槽时旧槽清空、卡移入目标槽）后关闭弹窗继续流程。
- 局终弹窗确认后直接回主菜单，不自动打开收藏页。
- 遮罩拦截穿透；Esc 无快捷路径，弹窗独占输入。弹窗瞬态不入存档（读档回到铸牌屏可重新铸造选择）。
