# 商店界面重排 · 界面描述

> 参考图：同目录「商店界面，选项选择商品.png」「商店界面，选项选择人格铸造.png」「牌型强化界面.png」「选择卡牌进行倍率强化的界面.png」「人格牌主词条强化界面.png」（网页版截图，排版的首要参考）。本批 = UI 界面重排第二批：商店主界面（商品页 + 人格铸造标签页）+ 3 个强化界面（选牌弹窗 / 牌型强化 / 人格主词条强化），全部已实现并接入商店流程。

## 状态与触发

- **状态**：已实现（新建 4 个 Prefab + 运行时注入，零场景改动）。
- **触发路径**：
  - 商店主界面：战斗节点 `hasShopAfter` 后置阶段进入（商店不是路线节点类型，是节点后置阶段）；
  - 选牌弹窗：商店服务区块点击 6 种单卡类服务（筹码强化/金币强化/倍率强化/独立乘区强化/花色强化/移除卡牌）；
  - 牌型强化界面：服务「牌型强化」；
  - 人格主词条强化界面：服务「人格主词条强化」。
- **旧屏处置**：旧商店屏「Shop Card」场景节点保留但不激活（运行时常年 SetActive(false)）；旧 EnhancementSelect「槽位语义切换」模式已整体删除，由 3 个新界面取代。

### 商品页（中列）

- 标签页：选中标签深棕底 (58,47,28,248) + PaleGold 字 (232,214,173)，未选黑底 (31,32,31,248) + 暗金字 (168,142,96)。
- 4 个商品位（卡牌 2 + 人格牌 2）：行文案「黑桃A · 2金币」/「黑桃A · 已售罄」/「无货」；选中行金色粗描边 (1.8,-1.8)，无货位不可选。人格位因白名单当前恒显示「无货」（B7 模板转换后恢复上架）。

### 右列商品详情

- 名称、类型标签（「类型·卡牌」/「类型·人格牌」/「类型·服务」）、效果描述（增加卡牌 → 卡牌名 + 花色符号解析）、价格（「2金币」/「已售罄」/「无货」）。

### 人格铸造标签页

- 8 人格列表（PersonaForgeCatalog 配表序 PER_001~008，GridLayoutGroup cell 560×54 单列滚动）：行 = 人格名 + 进度「0/2」；选中行金色粗描边。
- 右列铸造详情：人格名、词条触发条件（「连续两次使用相同牌型」）、「主属性 · 基础筹码」类型标签 + 效果（「基础筹码 +15」）、副属性槽位区（每人格 2 槽）。
- 副属性槽行：状态文案（未解锁「未解锁」；已解锁显示池内行效果「基础筹码 +8」）+ 解锁节点文案（「解锁节点：第一章 · 已到达/未到达」，仅展示不设门槛）+ 解锁按钮。
- 解锁按钮：「解锁 · 5金币」/「解锁 · 8金币」/「金币不足」/「已解锁」/「未解锁」（顺序未到时）。**5 金 → 8 金顺序解锁**，真实扣款，失败无副作用；进度「0/2」真实入档（schemaVersion 保持 3）。

## 选牌弹窗（6 种单卡类服务共用）

### 布局总览

模态覆盖（全屏遮罩 + raycast 拦截，商店主屏保持激活被覆盖）：

| 区块 | 说明 |
|---|---|
| 顶部标题栏 | 「选择商品作用的卡牌」+ 右上 × |
| 统计排序区 | 「总数 52 / 可选 52」+ 提示「请选择 1 张目标牌」+ 排序按钮「大小 / 花色」互斥（选中金底金框） |
| 卡牌网格 | 52 卡 10×6 GridLayoutGroup（cell 62×62，不复用 BattleCardView——其尺寸写死 112×168） |
| 底部商品信息栏 | 服务名 + 描述（随选中刷新）+「确认购买并应用」/「取消购买」 |

### 卡牌格

- 羊皮纸色卡面 (103,84,51,255)，左上点数（A/K/Q/J/数字）、中央花色符号（♠♥♦♣）深色字。
- 选中金色描边 (2.2,-2.2)；**不可选置灰**（CanvasGroup 0.35 且不可点）。
- 两式排序：大小 = 点数升序、同点数花色序（默认）；花色 = 花色序、同花色点数升序。

### 可选性规则（随服务种类）

| 服务 | 可选 |
|---|---|
| 筹码/金币/倍率/独立乘区强化 | 牌 Enhancement == None（单牌单增强槽，不覆盖已有增强） |
| 花色强化 | 该花色线未满级（< Lv4） |
| 移除卡牌 | 牌组高于 8 张下限 |

### 确认与扣款

- 信息栏描述随选中刷新：花色服务显示「{花色名} Lv{n}→Lv{n+1} · 费用 {真实价}」（8/11/14/17 按表）；移除显示「当前牌组 N 张」。
- 「确认购买并应用」：真实价扣款 + 应用（筹码 +5 / 倍率 +0.5 / 独立乘区 ×1.03 / 金币强化标记 / 花色线升 1 级 / 移除牌）；金币不足或应用失败 → 拒绝且无副作用，留在界面内提示。
- 成功后：服务槽标记售罄 → 关闭弹窗 → 状态文案「已购买 {name}，剩余金币 {coins}」→ 刷新商店 → 存档。

## 牌型强化界面 / 人格主词条强化界面（同构共用）

两界面共用 EnhanceListPanelView 骨架（一模板两 prefab），仅标题说明与选中样式不同：

| | 牌型强化 | 人格主词条强化 |
|---|---|---|
| 标题 | 牌型强化 | 人格主词条强化 |
| 说明 | 选择1种牌型，其原始基础筹码和基础倍率各提升10%。 | 选择1张人格牌，按主词条类型强化：筹码+10、倍率+0.3或独立倍率+10%。 |
| 候选 | 配表牌型序 11 种（含皇家同花顺，网页版只列 10 种已记确认）剔除满级/无价 | 装备槽非空人格牌（网页版 7 张示意，程序按装备 4 张已记确认）剔除满级/无价 |
| 行内容 | 牌型名 + 底值「基础 55 筹码 × 1 倍率」（Lv0 底）+ Lv.n | 人格名 + 效果「效果：+10 筹码」（无词条回落「类型：人格主词条」）+ Lv.n |
| 选中样式 | 蓝色高亮粗边 (60,110,180) | 浅金底色 (64,55,36) |
| 底部左侧 | 未选中「请选择目标」；选中「本次价格：8 金币」 | 「本次价格：8 金币」（无独立提示） |

- 布局：全屏覆盖面板 → 居中 Panel（金细边框）→ Header（左上「强化商品」小暗金 + 大标题亮金 + 说明暗金 + 金色细分割线）→ 候选 2 列 GridLayoutGroup（cell ~560×88 深底金框）→ Footer（左下价格/提示、右下「返回商店」深底亮金 +「确认购买」金填充深字，未选中禁用）。
- 确认：按当前等级真实价（8/11/14/17）扣款 + 升 1 级；金币不足拒绝且无副作用。牌型强化数值沿用现表（HandUp 等差增量），界面文案「各提升10%」为网页版近似。
- 「返回商店」= 销毁界面实例返回商店主屏（零状态机）。

## 交互汇总

- 商店主界面：标签切换 / 商品行选中 / 购买按钮 / 服务行直接打开对应界面 / 铸造行选中 / 副属性解锁（5→8 顺序、真实扣款、回调即存档）/ 离开按钮去向后缀。
- 三个强化界面均为遮罩独占输入；返回商店 = 销毁实例；确认成功统一后置（售罄 → 关闭 → 状态文案 → 刷新 → 存档）；取消/金币不足无副作用。
- 强化等级与副属性解锁均随存档读写；弹窗瞬态不入存档。
