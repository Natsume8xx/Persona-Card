## 〇、拍板与依据

- 范围（阶段计划已定）：首次进战斗自动播放五步教学（11.3.1 五主题：当前得分和目标分 / 手牌区与选牌 / 计分预览 / 人格牌区 / Boss协议区）；遮罩拦截出牌/弃牌/快捷键；可跳过；重播入口可用。
- 关键决策（本文档固化）：
  1. **教程载体 = 战斗画面**：策划 11.3.1 明确「教学进行时，遮罩外区域不响应战斗操作」——教学在战斗画面上播放：全屏半透明遮罩（Image raycastTarget=true 拦截下层按钮点击）+ 中央文本面板。五步主题区不做逐区美术高亮（用户约定先不做美术资源），以文案说明各区域位置。
  2. **快捷键现状**：代码库无空格/D 快捷键实现（策划 12.3.1 声明「出牌=空格、弃牌=D」但原型未实现，属 P0-1H 设置系统范畴）。遮罩拦截空格/D 以防御性吞键实现：FlowController 新增 Update，教程激活时吞 Space/D，留 TODO(P0-1H)——快捷键接入后由 TutorialActive 统一拦截，本次写好的拦截点天然生效。
  3. **重播入口 = 主菜单「战斗教学」按钮**（阶段计划写「主菜单/设置入口」二选一）：点击后标记重播请求 + 按钮文案改「✓ 下次战斗播放教学」（即时反馈），下一次进入战斗（新局或继续）自动播放。P0-1H 设置系统完成后在设置界面加同款入口（调同一方法，入口移交不重写逻辑）。
  4. **首次判定 = PlayerPrefs 持久标志**（key `PersonaCards.TutorialSeen`，int 0/1）：首次进战斗自动播放并写标志，跨局/跨会话生效；重播请求只触发播放、不读写标志（已看过的玩家仍可重播）。编辑器可 Clear All PlayerPrefs 重置。
  5. **教程文案自拟**：策划 11.3.1 只给五主题无具体文案，五步文案自拟并与主题一一对应；第五步 Boss 文案泛化不写死 Boss 名（代策划确认 C4 待答，本次采用泛化方案，策划回复后再行调整）。
  6. **逻辑抽纯类 TutorialSequence**（UI 程序集，EditMode 可测，模式同 PrototypeFlowStateMachine）：五步标题/正文 + Start/Next/Skip 状态推进 + ShouldAutoPlay 纯函数（测试不依赖 PlayerPrefs）；FlowController 只做 UI 接线与持久化。

## 一、开发内容

### 1. TutorialSequence（UI，新，纯 C# 类）
- `public const int StepCount = 5;` + `public static readonly string[] StepTitles/StepBodies;`——五步标题/正文自拟，与 11.3.1 五主题一一对应：
  1. 「得分与目标」：左上角当前得分 / 右上角目标分 / 出牌次数用完前达标即胜、用尽未达标即败。
  2. 「手牌与选牌」：点击手牌最多选 5 张（再点取消）；「出牌」打出；「弃牌」弃掉选中的牌并重抽。
  3. 「计分预览」：选牌时预览区实时显示牌型与预计得分；牌型越强得分越高。
  4. 「人格牌区」：满足条件自动触发，按槽位从左到右结算，加筹码或倍率。
  5. 「首领协议区」：首领战斗展示协议与介入事件，改变本场规则；阅读协议并围绕它调整策略（泛化，不写死 Boss 名）。
- 状态推进：`CurrentStep`（-1=未激活；0~4）；`Start()` → 0；`Next()` → 0..3 推进、4 → -1（结束）；`Skip()` → -1；`IsActive`；`GetTitle(int)/GetBody(int)` 越界返回空串。
- `public static bool ShouldAutoPlay(bool replayRequested, bool hasSeen)`：replayRequested 或 !hasSeen → true（纯函数，测试无需 PlayerPrefs）。

### 2. PrototypeFlowController（UI，改）
- 新字段：
  - `[SerializeField] private GameObject tutorialOverlay;`（教程遮罩根，Battle 屏子对象）
  - `[SerializeField] private Text tutorialStepText/tutorialTitleText/tutorialBodyText;`
  - `[SerializeField] private Button tutorialNextButton/tutorialSkipButton;`（面板内按钮）
  - `[SerializeField] private Button tutorialReplayButton;` + `[SerializeField] private Text tutorialReplayLabel;`（主菜单「战斗教学」按钮及其文案）
- 状态：`private readonly TutorialSequence _tutorial = new TutorialSequence();` + `private bool _tutorialReplayRequested;`
- PlayerPrefs：`private const string TutorialSeenKey = "PersonaCards.TutorialSeen";` + `HasSeenTutorial`（读）/`MarkTutorialSeen()`（写 1）。
- Configure 签名追加：`GameObject tutorialOverlay`、`Text tutorialStepText, Text tutorialTitleText, Text tutorialBodyText`、`Button tutorialNextButton, Button tutorialSkipButton`、`Button tutorialReplayButton, Text tutorialReplayLabel`；体末赋值。
- Awake 绑定：`tutorialNextButton → TutorialNext`、`tutorialSkipButton → TutorialSkip`、`tutorialReplayButton → RequestTutorialReplay`。
- `StartCurrentBattle()` 末尾调 `TryAutoPlayTutorial()`：`TutorialSequence.ShouldAutoPlay(_tutorialReplayRequested, HasSeenTutorial)` → 是：`_tutorial.Start()` + `MarkTutorialSeen()` + `_tutorialReplayRequested = false` + 日志 `[Flow] 开始战斗教学（5 步）。` + Render()。
- 公开状态：`public bool TutorialActive => _tutorial.IsActive;`
- 按钮方法：
  - `TutorialNext()`：推进；结束（CurrentStep 变 -1）时日志 `[Flow] 战斗教学结束。`；Render()。
  - `TutorialSkip()`：结束 + 日志 `[Flow] 战斗教学已跳过。`；Render()。
  - `RequestTutorialReplay()`：置标志 + `tutorialReplayLabel.text = "✓ 下次战斗播放教学"` + 日志 `[Flow] 已标记：下次进入战斗时播放教学。`。
- 新增 `Update()`：`if (_tutorial.IsActive && (Input.GetKeyDown(KeyCode.Space) || Input.GetKeyDown(KeyCode.D))) { /* 吞键 */ }`——策划 11.3.1「拦截空格、弃牌快捷键」；TODO(P0-1H)：当前原型无快捷键，此拦截为防御性，快捷键接入后天然防穿透。
- Render()：`tutorialOverlay.SetActive(_tutorial.IsActive);`；激活时刷新 step「教学 {n} / 5」/title/body/下一步按钮文案（末步「完成」、前四步「下一步」）。遮罩是 Battle 屏子对象，战斗屏隐藏时随之隐藏（教学仅在战斗中激活，无孤儿遮罩）。
