## 〇、拍板与依据

- 范围（阶段计划已定）：亮度 / 界面动效 / 屏幕震动 / 主音量四设置项；快捷键改键（出牌=空格、弃牌=D、设置=ESC）；恢复默认 / 取消 / 保存；本地 JSON 存储、异常回落默认。
- 关键决策（本文档固化）：
  1. **完成标准调和 12.3.1 与 12.6 的矛盾**：12.3.1 有「保存/取消」按钮，12.6 说「修改后立即保存并生效」。调和为：**修改即时生效（不落盘）→ 点「保存」才持久化 → 「取消/返回主界面/返回」回滚进入设置时的快照 → 「恢复默认」立即持久化覆盖**。四按钮语义与 12.3.1 文案一一对应。
  2. **「界面动效」开关 = 动效统一归口门面**（用户 2026-08-21 说明：目前系统还没有动效系统，以后会加上手牌动效和整体画面动效）：当前唯一的动效控制点是战斗屏「减少动效」Toggle（控制 `BattlePrototypeController.PresentationDuration()` 的出牌/结算展示时长）。拍板：`GameSettings.AnimationsEnabled` 为唯一归口——`PresentationDuration` 改读门面；**战斗屏「减少动效」Toggle 移除**（策划 12.3.1 只要求设置界面有开关，双入口状态纠缠无收益）；未来手牌/画面动效接入时同样读此门面，不再各做开关。
  3. **快捷键 = FlowController.Update 单一输入点**：教学激活时直接 return（P0-1G 的防御性吞键 TODO 就此兑现，拦截天然生效）；出牌/弃牌经 `BattlePrototypeController.OnPlay/OnDiscard` 公开化调用（与按钮共用入口）；ESC 仅主菜单（打开设置）与设置界面（关闭）响应，**战斗内 ESC 不响应**（原型无暂停系统，战斗内暂停+设置留待后续任务）。
  4. **设置界面 = 主菜单 overlay**（照抄 _collectionOpen 模式：`_settingsOpen`，全屏遮罩拦截下层点击）；入口 = 主菜单卡片内「设置」按钮，一行一个全宽（用户 2026-08-21 要求不并排：卡片内 5 按钮各占一行——开始/继续/收藏不动，「设置」占原「战斗教学」行 0.135~0.225，「战斗教学」下移 0.03~0.12，「版本文本」移出卡片挂主菜单屏底部 0.015~0.06）。
  5. **数据架构**（12.7 表结构为空，JSON schema 自定）：`GameSettingsData` POCO（JsonUtility 可序列化）+ `GameSettings` 静态门面（Apply 全量校验整体替换，非法拒绝保持旧状态）+ `GameSettingsStore`（独立文件 `persona-cards-settings-v1.json`，persistentDataPath，照抄 PrototypeSaveStore 的 tmp/bak 原子替换 + damaged 备份，schemaVersion=1）。**不混入战役存档**（PrototypeSaveStore 不动）。
  6. **默认值自定**：亮度 0.8 / 界面动效开 / 屏幕震动开 / 主音量 0.8 / 出牌 Space / 弃牌 D / 设置 Escape。键位校验：Key.None 拒绝、未定义枚举值拒绝、三键互异（重复拒绝）。
  7. **各设置项落地方式**：亮度 = Canvas 根 dim 层（黑 Image，raycastTarget=false，alpha = 1-亮度，创建于所有屏之后故为最上层 sibling，全局即时预览）；主音量 = `AudioListener.volume`（当前项目无音频文件，生效但无感，SceneBuilder 说明文本注明）；屏幕震动 = 出牌结算时 battleScreen 抖动协程（FlowController 已订阅 HandPlayed，触发时读门面）；界面动效 = `PresentationDuration` 读门面（见决策 2）。
  8. **改键交互**：点击键位按钮进入改键态（文案变「请按新按键…」，一切按键被捕获），按任意键替换（与另两键重复则拒绝并提示）；再次点击同一条目取消改键态。
  9. **设置内「重新查看战斗教学」按钮**：调用 P0-1G 的 `ToggleTutorialReplay` 同一逻辑；主菜单与设置内两处按钮文案由 `RefreshTutorialReplayLabels()` 统一同步。
  10. **「简易设置」不分页**（代策划确认 C3）：当前原型单一设置界面，不做简易/完整分页，代策划确认.md 记录。
  11. **日志前缀 `[Settings]`**。

## 一、开发内容

### 1. GameSettingsData（UI，新，纯 POCO）
- `[Serializable] public sealed class GameSettingsData`：
  - `public float brightness = 0.8f;`（亮度 0~1）
  - `public bool uiAnimation = true;`（界面动效）
  - `public bool screenShake = true;`（屏幕震动）
  - `public float masterVolume = 0.8f;`（主音量 0~1）
  - `public int playKey = (int)Key.Space;` / `discardKey = (int)Key.D;` / `settingsKey = (int)Key.Escape;`
  - `public int schemaVersion = 1;`
- 全字段带注释；默认值即拍板默认（`new GameSettingsData()` 即「恢复默认」目标）。

### 2. GameSettings 门面（UI，新，静态类）
- `private static GameSettingsData s_current = new GameSettingsData();`
- `public static GameSettingsData Current => s_current;`（引用只读；修改统一走 TryApply/ApplyDefault）
- `public static GameSettingsData Default() => new GameSettingsData();`
- `public static bool TryApply(GameSettingsData data)`：全量校验——brightness/masterVolume ∈ [0,1] 且非 NaN；三键 `Enum.IsDefined` 且非 `Key.None` 且互异。全部通过才整体替换并返回 true；任一失败拒绝（保持旧状态）返回 false。
- `public static void ApplyDefault()`（TryApply(Default())，恒成功）
- 便捷属性（含注释）：`Brightness` / `MasterVolume` / `AnimationsEnabled` / `ScreenShakeEnabled` / `PlayKey`（Key 枚举）/ `DiscardKey` / `SettingsKey`。

### 3. GameSettingsStore（UI，新）
- 构造器：`GameSettingsStore()`（默认 `Path.Combine(Application.persistentDataPath, "persona-cards-settings-v1.json")`）+ `GameSettingsStore(string filePath)`（测试注入临时路径）。
- `public bool TrySave(GameSettingsData data)` / `public bool TryLoad(out GameSettingsData data)`：照抄 PrototypeSaveStore——写 tmp 再 `File.Replace`（带 bak）原子替换；读损坏/解析失败/字段缺失 → 备份 `.damaged-时间戳` 并返回 false；schemaVersion ≠ 1 → 返回 false；全部异常吞掉返回 false（异常回落默认，12.6）。
- 日志前缀 `[Settings]`。

### 4. BattlePrototypeController（UI，改，动效归口）
- **删除** `reduceMotionToggle` 字段与 `ConfigureScene` 该参数（归口到 GameSettings，见 §〇-2）。
- `PresentationDuration(float normalDuration)`：改读 `GameSettings.AnimationsEnabled ? normalDuration : 0f`，注释说明动效统一归口。
- `OnPlay()` / `OnDiscard()` 由 private 改 **public**：注释「快捷键与按钮共用入口」。
- BeginBattle 无参调试入口不动。

### 5. PrototypeFlowController（UI，改）
- **新字段（[SerializeField]，设置屏引用）**：`settingsEntryButton`（主菜单「设置」入口按钮）、`settingsOverlay`（GameObject）、`brightnessSlider/brightnessValueText`（Slider/Text）、`volumeSlider/volumeValueText`、`animationToggle/shakeToggle`（Toggle）、`playKeyButton/playKeyLabel`、`discardKeyButton/discardKeyLabel`、`settingsKeyButton/settingsKeyLabel`（Button/Text）、`settingsTutorialReplayButton/settingsTutorialReplayLabel`、`settingsBackButton/settingsReturnButton/settingsRestoreDefaultsButton/settingsCancelButton/settingsSaveButton`（Button）、`dimImage`（Image，Canvas 根 dim 层）。
- **新方法 `ConfigureSettings(...)`**：独立签名接上述全部引用（Configure 主签名已近 40 参，不再膨胀），SceneBuilder 构建设置屏后调用；字段名进校验列表。
- **状态**：`_settingsOpen`、`_settingsSnapshot`（GameSettingsData）、`_rebinding`（enum RebindingTarget { None, Play, Discard, Settings }）、`_refreshingUi`（防 Slider 回环标志）。
- **Awake**：绑定 slider onValueChanged（去 percent）/ toggle onValueChanged / 按钮 onClick；`_store = new GameSettingsStore()` → `TryLoad` → `TryApply`（失败即回落默认）→ `RefreshAppliedSettings()`。
- **打开/关闭**：`OpenSettings()`（快照 Current → 刷新 UI → overlay SetActive(true) → `_settingsOpen = true`）、`CloseSettings()`（SetActive(false)，仅隐藏不回滚）；「返回主界面」「返回」按钮 = CancelSettings + CloseSettings。
- **修改即生效**：滑条/开关回调 → 改 Current 对应字段（单字段更新，整体重新 TryApply 校验通过才生效——滑条只会给合法值）→ `RefreshAppliedSettings()`（AudioListener.volume、dim alpha）→ 刷新百分比文本。
- **键位**：点键位按钮 → 进改键态（对应 label「请按新按键…」）；Update 改键态 → 遍历 `Keyboard.current.allKeys` 取 wasPressedThisFrame 键 → 与另两键重复则提示「与 X 键重复」保持改键态，合法则替换 Current 对应键 + 退出改键态 + 刷新文案；再点同一条目 → 取消改键态。
- **Update 快捷键**：`_tutorial.IsActive` → return（吞键）；`_rebinding != None` → 捕获（见上）return；`settingsKey.wasPressedThisFrame` → 阶段 MainMenu 时 OpenSettings、SettingsOpen 时 CloseSettings（其余阶段忽略）；`playKey/discardKey.wasPressedThisFrame` → 阶段 Battle 时调 `battleController.OnPlay()/OnDiscard()`（Keyboard.current 判空防无键盘设备）。
- **保存/取消/默认**：`SaveSettings()`（TrySave(Current) + 日志 + 提示文案）；`CancelSettings()`（TryApply(_settingsSnapshot) → RefreshAppliedSettings + RefreshSettingsUi + 退出改键态）；`RestoreDefaults()`（ApplyDefault + TrySave 立即落盘 + 刷新，12.6 恢复默认覆盖本地）。
- **`RefreshAppliedSettings()`**：`AudioListener.volume = Current.MasterVolume;` + `dimImage.color.a = 1 - Current.Brightness`。
- **`RefreshSettingsUi()`**：_refreshingUi 防环下刷 slider 值/百分比文本/toggle isOn/键位按钮文案（`KeyDisplayName(Key)`：Space→「空格」、Escape→「ESC」、其余枚举名）/教学按钮文案。
- **屏幕震动**：`OnHandPlayed` 内 `if (GameSettings.ScreenShakeEnabled)` → `StartCoroutine(ShakeScreen())`——battleScreen RectTransform 抖动（0.25 秒、±6px、线性衰减复位）。
- **教学按钮文案同步**：`ToggleTutorialReplay()` 内改调 `RefreshTutorialReplayLabels()`（主菜单 + 设置内两个 label 同步「战斗教学 / ✓ 下次战斗播放教学」）。

## 四、人工走查（策划视角）

1. 主菜单卡片第 4 行「设置」按钮（收藏与战斗教学之间，一行一按钮）→ 设置界面弹出，遮罩下主菜单按钮点不到；「← 返回」/底部「返回主界面」→ 回主菜单。
2. 拖「亮度」滑条：百分比文本实时变化、全屏明暗即时预览；拖「主音量」：百分比实时变化（当前无音频文件，音量数值已写入 AudioListener）。
3. 「界面动效」关 → 进战斗出牌/弃牌：结算等待动画消失（即时结算）；开 → 恢复动画。
4. 「屏幕震动」开 → 出牌结算时画面抖动；关 → 不抖。
5. 快捷键：战斗中按空格 = 出牌、D = 弃牌；教学弹出期间空格/D 无反应（吞键）；战斗内按 ESC 无反应。
6. 改键：点「出牌：空格」→ 变「请按新按键…」→ 按 K → 显示「出牌：K」→ 战斗中按 K 出牌；改键时按与弃牌相同的键 → 提示重复不生效；再点条目退出改键态。
7. 保存/取消：改亮度 → 「保存」→ 退出 Play 重开 → 亮度保持；改亮度 → 「取消」→ 回滚到进设置前的值；不点保存直接「返回主界面」→ 修改不生效。
8. 「恢复默认」：乱改几项 → 恢复默认 → 全部回默认值，且退出重开仍是默认（立即落盘）。
9. ESC：主菜单按 ESC 打开设置；设置界面按 ESC 关闭；设置内「重新查看战斗教学」点击 → 文案变「✓ …」且主菜单按钮同步 → 开战自动弹教学。
10. 回归：P0-1G 五步教学链路、P0-1F HUD 分母、收藏/装备、继续游戏均不受影响。

## 五、风险与回退

- **静态 GameSettings 污染测试**：GameSettingsTests 加 [TearDown] ApplyDefault；其他测试不读门面（PresentationDuration 属 Play 期逻辑）。
- **Slider 值回写触发 onValueChanged 死循环**：`_refreshingUi` 标志统一防环。
- **dim 层挡交互**：raycastTarget=false；仅视觉压暗。
- **改键态吞掉一切键**（含 ESC）：再点同一条目即退出改键态（设置界面底部按钮可点，不依赖键盘）。
- **移除战斗屏「减少动效」Toggle**：若用户希望保留战斗内快捷开关，回退方案 = SceneBuilder 恢复创建 + onValueChanged 同步门面（改动小，本文档已留口）。
- **战斗内 ESC 不响应**：原型无暂停系统，拍板如上；战斗内暂停+设置留待后续任务（阶段计划后续项）。
- **设置存档损坏**：damaged 备份 + 回落默认；与战役存档（PrototypeSaveStore）完全独立，互不影响。
