## 一、开发内容

### 1. 配置枚举（Battle.Personas，新，4 个文件）
与运行时枚举分离，专供配置数据面（`PersonaCardDefinition`/`PersonaScoringEffect` 的 `PersonaConditionKind`/`PersonaEffectKind` 不动）：
- `PersonaQuality { Basic = 1, Advanced = 2, Rare = 3, Mutant = 4 }`：基础/进阶/稀有/异质（A1；Mutant=「异质」）。
- `PersonaTriggerCondition`（12 种，按表出现序）：`SameHandTypeAsPrevious`（与上一手牌型相同）、`ScoringCardCount`（计分牌数量）、`DiscardsUsed`（已使用弃牌次数）、`HitAiPreference`（命中AI偏好）、`DiscardsRemaining`（剩余弃牌次数）、`CardsRemovedThisRun`（本局移除牌数量）、`CardsAddedThisRun`（本局新增牌数量）、`SameHandTypeStreak`（连续使用相同牌型次数）、`DeckSize`（牌库数量）、`OtherPersonaTriggerCount`（其他人格触发次数）、`PlaysRemaining`（剩余出牌次数）、`PersonaTriggerCount`（人格触发次数）。
- `PersonaComparator { Equal, GreaterOrEqual, Less, LessOrEqual }`：等于/大于等于/小于/小于等于。
- `PersonaEffectType { AddChips, AddMultiplier, AddChipsAndMultiplier, PerUnitMultiplier, PerUnitChips, MultiplyFinal }`：增加筹码/增加倍率/增加筹码和倍率/每单位增加倍率/每单位增加筹码/最终倍率乘算。

### 2. PersonaCardTemplate（Battle.Personas，新）
- 纯数据 POCO 承载 15 列全量：PersonaId/DisplayName/Quality/QualityParam(原文，颜色暂定)/BehaviorTagId/TriggerCondition/Comparator/ConditionThreshold(int?)/ExtraCondition(ExtraConditionSpec?)/ExtraConditionRaw(原文)/EffectType/EffectParam1(decimal)/EffectParam2(decimal)/EffectRaw(原文)/EffectCap(decimal?)/IndependentSettlement(bool)。
- 构造器校验：PersonaId 允许空（同 P0-1C/1D cardId 语义——不，此处 personaId 是权威查询键，非空；与 P0-1D 不同）、名称非空、四枚举 Enum.IsDefined、EffectParam1/2 ≥ 0、EffectCap ≥ 0（非空时）、Threshold ≥ 0（非空时）。
- `ExtraConditionSpec` 小 POCO：TriggerCondition/Comparator/Threshold。
- 静态 TryMap ×4（映射表 + 反向映射供日志）：`TryMapQuality/TryMapTrigger/TryMapComparator/TryMapEffectType`（string→枚举，含「特殊」→Mutant 兼容？——**不**：「特殊」规范化发生在 Mapper 层，门面转换表只认规范值 4 种，防双处兼容漂移）。

### 3. InitialPersonaCatalog → 门面（Battle.Personas，改）
- 保留类名与旧 API 零改动：`Accumulator/Executor/Ambitious` 静态属性（白盒教学 3 张，幂等缓存实例）、`CreateDefaultLoadout()`（3 教学 + 空槽 4）。
- 新增：
  - `Configure(IReadOnlyList<PersonaConfigEntry> entries)`（编译期修正：Battle 是 noEngineReferences 程序集，资产类型（ScriptableObject）不能跨边界——P0-1D 教训，入口是纯条目列表而非资产）：null/空列表 → 空模板目录（回落白盒）；遍历转换（TryMap 失败 → ArgumentException → catch → 整体回落空目录，防半状态）；成功摘要 `"{n} 张人格牌模板已加载。"` 经 `LastConfiguredSummary` 由调用方打 `[Persona]` 日志。
  - `Templates`（IReadOnlyList<PersonaCardTemplate>，按 PersonaId 升序）、`TryFind(string personaId, out PersonaCardTemplate)`、`LastConfiguredSummary`。
- 转换函数 `ToTemplate(asset.Entry)` 私有；映射表与契约常量交叉校验测试防漂移（同 P0-1D）。

### 4. PersonaConfigAsset（Data，新）
- `[CreateAssetMenu(menuName = "PersonaCards/PersonaConfig", fileName = "PersonaConfig")]`，路径常量 `Assets/PersonaCards/Data/PersonaConfig.asset`。
- `PersonaConfigEntry` 顶层纯 C# 类（**非资产嵌套类**——noEngineReferences 边界要求，编译期修正）：personaId/displayName/quality(string 规范后 4 值)/qualityParam/behaviorTagId/trigger(string)/comparator(string)/threshold(string 原文，空=无)/extraTrigger(string?)/extraComparator(string?)/extraThreshold(string 原文，空=无)/extraConditionRaw(string?)/effect(string)/effectParam1(string 原文必填)/effectParam2(string 原文，空=0)/effectRaw(string)/effectCap(string 原文，空=无)/independentSettlement(bool)。
- `Validate(out string)`：条目非 null、personaId 非空且唯一、名称非空、四文本枚举合法（quality 仅 4 规范值）、behaviorTagId 空或 `T\d{2}` 格式、threshold/effectParam1/effectParam2/effectCap string 原文非负（invariant parse）、extraTrigger 非空时 extraComparator/extraThreshold 必须有效（反之半空 = 错误）、independentSettlement 恒有值（bool 无校验）。（PER_001~016 齐全校验在 Mapper 层，不在此层——空白盒资产合法。）

### 5. PersonaTableMapper + 契约（Data，新）
- `PersonaTableContract`：SheetName「人格牌配置」；列 人格牌_ID/人格牌名称/品质类型/品质参数/行为标签_ID/触发条件/比较符/条件阈值/附加条件/效果类型1/效果参数1/效果参数2/效果/效果上限/独立结算；合法值集合：品质 4 规范值 + 兼容「特殊」、触发条件 12 文本、比较符 4 文本、效果类型 6 文本、独立结算「是/否」。
- `PersonaTableMapper.Map(rows, ICollection<string> imageBindingIds)`（复用 ImageSheetContract 读图片配置绑定 ID）行级全量校验、错误全收集：
  - 人格牌_ID 空/重复 = 错误；不在图片配置绑定 ID = 警告容错（PER_001~016 已在图片配置中 → 预期零警告）。
  - 品质类型 =「特殊」→ 规范化「异质」+ 警告；未知 = 错误。
  - 触发条件/比较符/效果类型1 未知 = 错误；独立结算 ≠ 是/否 = 错误。
  - 条件阈值：空允许；非负整数（否则错误）。效果参数1：非负 decimal（否则错误）。效果参数2：空=0、非负 decimal。效果上限：空允许、非负 decimal。
  - 附加条件：空 = 无；「{条件}{比较符}{阈值}」可解析（拆分已知条件文本 + 已知比较符 + 非负整数）→ 结构化三个字段；**不可解析 → 存 extraConditionRaw 原文 + 警告**（PER_013 带星号命中此路）。
  - 名称空 = 错误；behaviorTagId 非空时 `T\d{2}` 格式校验。
  - **PER_001~016 齐全检查**：缺任一 = 错误「请确认该行未被误删」；多出的 ID 允许。
- 产物按人格牌_ID 升序；返回 `PersonaMappingResult { Succeeded, Entries(资产 Entry 列表), Errors, Warnings }`。（Mapper 直接产出资产 Entry——Data 不能引用 Battle 类型，P0-1D 的「Mapper→POCO」改为「Mapper→资产 Entry」；Entry 数值列存 string 原文——threshold/extraThreshold/effectParam1/effectParam2/effectCap，空 = 无/0，门面 Configure 转换时再 parse。）

### 6. PersonaImportCommand（UI/Editor，新）
