# 人格牌 Unity MVP：已冻结设计决策

更新日期：2026-08-11

以下决策作为首个 Unity MVP 的开发基线：

1. 首个可交付版本采用 3 场战斗的垂直切片，闭环稳定后扩展至 6 场战斗、5 次商店与 3 个 Boss。
2. 牌型数值以完整 GDD 数值表为唯一权威，网页 Demo 的简化数值不进入正式实现。
3. 初始人格牌为积累者、执行者、野心者，第四槽为空。
4. UI 展示独立乘区明细，但权威计算只存在于规则层。
5. 普通战使用轻量观察者/规则区域；完整 Boss 区仅在 Boss 节点启用。
6. MVP 使用线性节点流程，不实现可选路线地图。
7. 战斗失败即结束本局，不允许当前关卡重试。
8. 首版商店只实现删除、重刻与强化，不保留网页 Demo 的免费 `+3` 测试入口。
9. 设置支持主音量、BGM 与 SFX；首版不支持按键重绑定与手柄验收。
10. 首发平台为 Windows PC，以 1920×1080、16:9 为基准，最低支持 1280×720。
11. 本地模板与降级闭环先行，真实 AI 后端作为 P1，不阻塞 MVP。
12. 开发期使用统一符号占位资产；正式视觉采用离线制作并人工审核，禁止运行时 AI 生图。
